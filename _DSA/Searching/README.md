# 📂 Searching Algorithms

**Searching Algorithms** are methods for locating a target value within a data structure. These techniques range from basic binary search to more specialised searches in rotated arrays or finding specific order statistics.

## 📌 **Common Problems**

1. **Binary Search** (Recursive & Iterative)
2. **Search in a Rotated Sorted Array**
3. **Find the Peak Element in an Array**
4. **Find the Square Root of a Number** (using Binary Search)
5. **Median of Two Sorted Arrays**
6. **Kth Smallest/Largest Element in an Array**

## Approach

### **1️⃣ Binary Search Fundamentals**

- **Recursive & Iterative:** Implement binary search using both approaches for clarity and efficiency.
- **Problem Variants:** Adapt binary search to handle rotated arrays, square roots, and order statistics.

### **2️⃣ Specialised Techniques**

- **Rotated Array:** Adjust the binary search boundaries based on pivot points.
- **Peak Element:** Use modified binary search to find local maximum efficiently.
- **Median & Kth Element:** Combine binary search with partitioning or two-pointer methods for optimal performance.
