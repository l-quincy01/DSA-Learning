# 📂 Arrays & Strings

An **Array** is a linear data structure that stores elements in contiguous memory locations, allowing constant-time access. A **String** is a sequence of characters, often implemented as an array.

## 📌 **Common Problems**

1. **Two Pointers Technique** (Sorting, Searching, Palindromes)
2. **Sliding Window** (Longest Substring, Maximum Sum Subarray)
3. **Kadane’s Algorithm** (Maximum Subarray Sum)
4. **Prefix Sum & Difference Arrays** (Range Queries, Equilibrium Index)
5. **String Manipulation** (Anagrams, Subsequence Matching, Reversal)

## Approach

### **1️⃣ Two Pointers**

- Used for sorting, merging, and searching problems.
- Efficient for problems involving pairs and subarrays.

### **2️⃣ Sliding Window**

- Dynamic window size to optimise searching in arrays & strings.
- Useful for longest/shortest substring problems.

### **3️⃣ Hashing & Prefix Sum**

- Speeds up searches in arrays & string frequency problems.
- Efficient for range queries and subarray problems.
