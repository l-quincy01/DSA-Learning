# 📂 Trees

A **Tree** is a hierarchical data structure that consists of nodes. It is widely used for organising data efficiently, such as in databases, file systems, and search algorithms. Trees help solve problems like searching, sorting, and hierarchical representation.

## 📌 **Common Problems**

1. **Tree Traversals** (Inorder, Preorder, Postorder)
2. **Binary Search Tree (BST) Operations** (Insert, Delete, Search)
3. **Find the Lowest Common Ancestor (LCA)**
4. **Convert a BST to a Balanced BST**
5. **Construct a Tree from Inorder & Preorder/Postorder Traversals**

## Approach

### **1️⃣ Recursive Traversal**

- Uses recursion for traversal (Preorder, Inorder, Postorder).
- Simple but uses extra stack space.

### **2️⃣ Iterative Traversal**

- Uses a stack for **DFS** (Depth-First Search).
- Uses a queue for **BFS** (Level-Order Traversal).

### **3️⃣ Binary Search Tree (BST) Properties**

- Left subtree contains smaller values.
- Right subtree contains larger values.
- Allows efficient searching (O(log N)).
