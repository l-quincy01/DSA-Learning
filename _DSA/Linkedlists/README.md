# 📂 Linked Lists

**Linked Lists** are a linear data structure where elements are stored in nodes, each containing data and a reference to the next node. They provide dynamic memory allocation and enable efficient insertion and deletion operations.

## 📌 **Common Problems**

1. **Singly Linked List Operations** (Insertion, Deletion, Search)
2. **Doubly Linked List Operations**
3. **Circular Linked List Handling**
4. **Reversing a Linked List**
5. **Cycle Detection**

## Approach

### **1️⃣ Iterative Methods**

- Traverse the list using loops.
- Simplifies pointer manipulation for standard operations.

### **2️⃣ Recursive Techniques**

- Utilise recursion to process nodes.
- Offers elegant solutions for tasks such as list reversal.
