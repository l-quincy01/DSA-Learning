# 📂 Mathematical Problems

This folder focuses on algorithmic challenges in number theory and arithmetic computations. It covers efficient techniques for prime checking, calculating the greatest common divisor, exponentiation, and more.

## 📌 **Common Problems**

1. **Prime Number Checking** (Sieve of Eratosthenes)
2. **Greatest Common Divisor (GCD)** (Euclidean algorithm)
3. **Exponentiation** (Exponentiation by Squaring)
4. **Count Trailing Zeros in Factorial**
5. **Find Missing Numbers in an Arithmetic Progression**

## Approach

### **1️⃣ Efficient Computations**

- **Prime Checking:** Utilise the Sieve of Eratosthenes for generating primes.
- **GCD Calculation:** Apply the Euclidean algorithm for quick computation.
- **Exponentiation:** Use exponentiation by squaring for optimised power calculations.

### **2️⃣ Problem-Specific Techniques**

- **Factorial Zeros:** Analyse prime factors to determine the number of trailing zeros.
- **Arithmetic Progression:** Leverage properties of progressions to identify missing numbers.
