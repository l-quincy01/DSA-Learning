# 📂 Sorting Algorithms

**Sorting Algorithms** are methods used to rearrange elements in a list in a particular order, typically ascending or descending. They are essential for organising data and serve as the backbone for many more complex algorithms.

## 📌 **Common Problems**

1. **Bubble Sort**
2. **Selection Sort**
3. **Insertion Sort**
4. **Merge Sort**
5. **Quick Sort**
6. **Heap Sort**

## Approach

### **1️⃣ Basic Comparison Sorts**

- **Bubble, Selection, Insertion Sort:** Simple to implement and understand, but generally less efficient on larger datasets.

### **2️⃣ Advanced Divide & Conquer**

- **Merge Sort & Quick Sort:** Utilise recursive divide-and-conquer strategies for improved efficiency.
- **Heap Sort:** Employs a heap data structure to maintain order during sorting.
