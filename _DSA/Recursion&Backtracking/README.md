# 📂 Recursion & Backtracking

**Recursion & Backtracking** is a problem-solving approach that uses recursive calls to explore possible solutions, reverting decisions when a path proves unviable. It is essential for tackling puzzles, combinatorial problems, and optimisation challenges.

## 📌 **Common Problems**

1. **N-Queens Problem**
2. **Permutations & Combinations**
3. **Subset Sum Problems**
4. **Maze Solving**
5. **Sudoku Solver**
6. **Factorial Calculation**
7. **Fibonacci Sequence** (Recursive & Dynamic Programming)

## Approach

### **1️⃣ Recursive Exploration**

- **Divide and Conquer:** Break problems into smaller subproblems.
- **Backtracking:** Revert decisions when a chosen path fails, exploring alternative solutions.

### **2️⃣ Optimisation Strategies**

- **Pruning:** Eliminate infeasible or redundant paths early.
- **Memoisation:** Cache intermediate results, especially for Fibonacci using DP.
