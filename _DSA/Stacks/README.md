# 📂 Stacks & Queues

**Stacks & Queues** are fundamental data structures used to manage data in a specific order. They underpin many algorithmic challenges, from expression evaluation to caching and sliding window problems.

## 📌 **Common Problems**

1. **Implement a Stack** (using arrays or linked lists)
2. **Implement a Queue** (using stacks)
3. **Next Greater Element**
4. **Valid Parentheses** (Balanced Brackets)
5. **Evaluate Reverse Polish Notation** (Postfix Expression)
6. **LRU Cache Implementation**
7. **Implement Min Stack** (Stack with getMin() in O(1))
8. **Sliding Window Maximum** (Max in every k-sized subarray)

## Approach

### **1️⃣ Data Structure Implementations**

- **Stack & Queue:** Build stacks with arrays or linked lists; simulate a queue using two stacks.
- **Min Stack & LRU Cache:** Enhance basic stacks to support additional operations efficiently.

### **2️⃣ Problem-Specific Techniques**

- **Next Greater Element & Valid Parentheses:** Use stacks to track and compare elements for efficient resolution.
- **Reverse Polish Notation:** Leverage stacks for evaluating postfix expressions.
- **Sliding Window Maximum:** Utilise a deque or specialised data structure to maintain the maximum in each window.
